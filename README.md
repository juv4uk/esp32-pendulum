# esp32-pendulum

Вимірювання **періоду**, **Q**, затухання та **g** фізичного маятника через AS5600 на ESP32-S3.

Дві цілі: реальний вимірювальний інструмент + навчальний проєкт з C (без абстрактних вправ).

---

## Стан зараз

**Скелет.** CMake, заголовки, `.c` з TODO. Ще не збиралось і не прошивалось у цьому середовищі (потрібен ESP-IDF у тебе локально).

---

## З чого почати (порядок навчання)

1. **`components/math/rational.c`** — раціональна арифметика, без заліза. Тут одразу видно переповнення.
2. **`components/drivers/as5600.c`** — I2C і помилки шини.
3. **`components/physics/*.c`** — по одному файлу вздовж конвеєра (синтетичний вхід замість датчика).
4. **`components/tasks/*.c`** — FreeRTOS в кінці, коли логіка вже перевірена.

**Правило:** у конвеєрі **немає `float`/`double`**. Лише `Rational32`/`Rational64`. `double` — максимум на виході в консоль.

---

## Залізо

- **ESP32-S3-N16R8** — перевір, що саме ця плата в наявності, перед `idf.py set-target`
- **AS5600** — магнітний кут, I2C, 12-біт (0..4095)

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p <порт> flash monitor
```

## Архітектура

```text
components/
  math/      Rational32/64 (overflow-safe)
  drivers/   as5600.c
  physics/   один крок = один файл
  tasks/     тонкі FreeRTOS-обгортки
main/
  app_main.c
```

Конвеєр:

```text
AS5600 (0..4095, wrap)
  → unwrap          неперервний кут
  → velocity        ω
  → period_estimator  T
  → peak_detector     амплітуди
  → quality_factor    Q без log()/math.h
  → gravity           g з T і довжини
```
